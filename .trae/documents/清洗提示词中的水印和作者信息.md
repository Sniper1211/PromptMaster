# 清洗提示词中的水印和作者信息

## 1. 编写清洗脚本 (`scripts/clean-watermarks.js`)
- **目标**：遍历所有提示词，移除包含水印、作者署名或无关元数据的文本行。
- **匹配规则**：
  - `Watermark in ...`
  - `右下角水印：...`
  - `The prompt continues in ...`
  - `Nano Banana` 相关署名
  - `By [Author]` 模式
- **逻辑**：
  - 连接数据库。
  - 遍历所有记录。
  - 对 `content`, `chinese_content` 等字段应用正则替换。
  - 记录被修改的 Prompt ID 和标题。
  - 执行 `UPDATE` 操作。
  - 输出 Markdown 格式的修改日志。

## 2. 执行与报告
- 运行脚本。
- 将脚本输出的 Markdown 表格提供给用户，列出所有被清洗的条目。

## 3. 执行顺序
- 创建并运行清洗脚本。
