# 修复提示词中的换行符转义问题

## 1. 编写修复脚本 (`scripts/fix-newlines.js`)
- **目标**：遍历数据库中的所有提示词，将错误的字符串字面量 `\n` 替换为真正的换行符。
- **范围**：检查 `content`、`chinese_content`、`description`、`description_zh` 等文本字段。
- **逻辑**：
  - 连接数据库。
  - 获取所有 ID 和相关字段。
  - 在内存中执行 `replace(/\\n/g, '\n')`。
  - 只有当内容发生变化时，才执行 `UPDATE` SQL。
  - 输出修复统计信息。

## 2. 执行与验证
- 运行脚本。
- 请用户在前端随机抽查几个之前有问题的提示词，确认换行显示是否正常。

## 3. 执行顺序
- 创建并运行修复脚本。
