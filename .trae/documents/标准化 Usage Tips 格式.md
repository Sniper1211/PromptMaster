# 标准化 Usage Tips 格式

## 1. 编写标准化脚本 (`scripts/standardize-tips.js`)
- **目标**：将所有非标准格式（单语言或纯文本）的 `usage` 字段转换为标准的双语格式。
- **筛选条件**：`usage` 不为空，且不包含 `### Chinese Tips` 标记。
- **处理逻辑**：
  - 读取现有的 `usage` 内容。
  - 调用 AI (OpenAI/DeepSeek)，要求将其重写为标准的双语 JSON (`usage_zh`, `usage_en`)。
  - 如果原内容是英文，则保留并翻译成中文；如果是中文，则保留并翻译成英文。
  - 拼接成标准格式字符串。
  - 更新数据库。
- **输出**：生成 Markdown 表格，列出被标准化的 ID、标题和原内容片段。

## 2. 执行与验证
- 运行脚本。
- 将生成的报告表格提供给用户。

## 3. 执行顺序
- 创建并运行标准化脚本。
