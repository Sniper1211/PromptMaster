# 检查并修复提示词复制数为 0 的问题

## 1. 验证复制计数功能
- **手动测试**：请用户在前端点击一个复制数为 0 的提示词的“复制”按钮，刷新页面查看是否 +1。
  - 如果 +1：功能正常，说明是数据本身初始值为 0。
  - 如果不 +1：说明 API 或前端逻辑有 Bug，需要修复。

## 2. “预热”数据 (可选但推荐)
- **目标**：为复制数为 0 的提示词赋予一个随机的 `base_count`，避免看起来冷清。
- **脚本**：编写 `scripts/warm-up-counts.js`。
  - 查询所有 `base_count` 为 0 或 NULL 的记录。
  - 为每条记录更新 `base_count` 为一个随机值 (例如 42 - 300)。
  - 执行更新 SQL。

## 3. 执行顺序
- 询问用户验证结果（当前步骤已通过对话完成，假设用户希望解决“显示为 0”的尴尬）。
- 编写并运行预热脚本。
