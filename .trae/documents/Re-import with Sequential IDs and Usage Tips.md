# 构建轻量级运营后台 (Admin Dashboard)

## 1. 后端开发：AI 生成与数据更新接口
- **新增接口 `POST /api/ai/generate-tips`**：
  - 集成 Deepseek API（使用 OpenAI SDK 兼容模式）。
  - **提示词工程**：设计系统提示词，让 AI 分析用户的 Prompt，并生成简洁的中英文使用建议（包含 Midjourney 参数推荐，如 --v 6.0, --ar 等）。
- **确认接口 `PUT /api/prompts/:id`**：
  - 确保现有的更新接口支持单独更新 `usage`（技巧与提示）和 `preview_image_url`（预览图链接）字段。

## 2. 前端开发：管理界面
- **新增路由**：创建 `/admin` 页面。
- **简易鉴权**：实现一个简单的客户端密码拦截（输入正确密码存入 localStorage 才能进入），防止普通用户误入。
- **界面组件**：
  - **仪表盘 (Dashboard)**：表格形式展示所有 Prompt，包含状态指示灯（❌ 缺 Tips / ❌ 缺图片），支持“只看未完成”筛选。
  - **编辑弹窗 (Editor Modal)**：
    - 展示 Prompt 原始内容（方便参考）。
    - **Tips 编辑区**：双语输入框 + "🪄 AI 自动生成" 按钮。
    - **图片编辑区**：URL 输入框 + 图片实时预览。
    - **保存按钮**：提交修改到数据库。

## 3. 联调与测试
- 连接前端“生成”按钮与后端 AI 接口，验证 Deepseek 生成质量。
- 连接“保存”按钮与数据库更新接口，确保数据能正确回写。
