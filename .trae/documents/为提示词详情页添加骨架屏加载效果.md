# 为提示词详情页添加骨架屏加载效果

## 1. 创建骨架屏组件 (`src/components/detail/PromptDetailSkeleton.tsx`)
- **目标**：创建一个与 `PromptDetailPage` 布局结构一致的骨架屏。
- **结构**：
  - **Navbar**：顶部占位条。
  - **主体区域**：模拟标题、标签、大图、描述文本、代码块和用法说明的灰色占位块。
  - **侧边栏**：模拟操作卡片（复制按钮区域）和标签云区域。
- **样式**：使用 Tailwind 的 `animate-pulse` 和灰色背景 (`bg-slate-200/300`)，保持与现有 Neo-Brutalism 风格一致的粗边框占位。

## 2. 集成到详情页 (`src/pages/PromptDetailPage.tsx`)
- **引入组件**：导入 `PromptDetailSkeleton`。
- **替换 Loading 逻辑**：将原有的 `if (detailLoading) return <Spinner ... />` 替换为返回 `<PromptDetailSkeleton />`。

## 3. 执行顺序
- 创建组件文件。
- 修改页面文件。
