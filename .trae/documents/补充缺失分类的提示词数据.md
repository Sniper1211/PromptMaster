# 补充缺失分类的提示词数据

## 1. 准备数据 (`scripts/data/missing-prompts.json`)
- 为以下 8 个分类各生成 3 条高质量提示词（共 24 条）：
  - **CODING**: Python 爬虫、React 组件优化、SQL 查询生成。
  - **WRITING**: SEO 博客大纲、深情情书、产品发布文案。
  - **BUSINESS**: SWOT 分析、商业计划书摘要、会议纪要整理。
  - **PRODUCTIVITY**: 每日计划生成、邮件礼貌回复、复杂概念简化。
  - **MARKETING**: Instagram 帖子灵感、邮件营销标题、用户画像分析。
  - **FUN**: 角色扮演（海盗）、生成冷笑话、emoji 故事翻译。
  - **SEO**: 关键词研究、Meta 描述生成、内容差距分析。
  - **LEARNING**: 费曼学习法解释、语言学习对话伙伴、历史事件模拟。

## 2. 编写填充脚本 (`scripts/seed-missing-categories.js`)
- 读取上述 JSON 数据。
- 连接数据库。
- 批量插入（使用 `INSERT INTO prompts ...`）。
- 确保 ID 自动递增。

## 3. 执行与验证
- 运行脚本。
- 再次运行 `scripts/count-categories.js` 验证各分类数量。
- 指导用户在网页前端验证。
