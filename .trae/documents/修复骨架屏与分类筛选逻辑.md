# 修复骨架屏与分类筛选逻辑

## 1. 修复 Sidebar 分类显示 (`Sidebar.tsx`)
- **问题**：目前分类列表基于 `prompts` 动态生成，导致分页加载时分类显示不全。
- **修复**：
  - 改为使用预定义的静态分类列表（`Category` 枚举的所有值）。
  - **移除分类计数**（因为前端无法计算全量计数，且为了性能暂不请求额外 API）。
  - 确保点击分类时正确传递 `Category` 值给父组件，从而触发后端筛选。

## 2. 优化 SkeletonGrid (`SkeletonGrid.tsx`)
- **问题**：CSS Grid 与 Masonry 布局不一致，导致闪烁。
- **修复**：
  - 在 `SkeletonGrid` 中引入 `react-masonry-css`。
  - 使用与 `PromptGrid` 完全相同的 `breakpointColumnsObj` 配置。
  - 确保 SkeletonCard 的外边距和样式与真实卡片一致。

## 3. 执行顺序
- 修改 Sidebar。
- 修改 SkeletonGrid。
