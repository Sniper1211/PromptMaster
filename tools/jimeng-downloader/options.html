PentaPrompt 即梦无水印下载

从即梦页面提取无水印原图，一键保存到本机的 pm-images 文件夹，文件名使用提示词 ID（如 16.webp），方便和 PentaPrompt 的补图清单对应。

保存文件夹

尚未选择保存文件夹

请选择本机的 ~/pm-images 文件夹（就是你放补图的那个目录）。浏览器出于隐私不会显示完整路径，只显示文件夹名，请自己确认选对。

第一次选择后，扩展会把文件夹句柄保存在本机浏览器里；之后在弹窗里点下载就直接写入，不需要再选。如果 Chrome 提示权限，请允许。

使用方法

1. 在即梦打开生成结果页面（能看到图片的页面）。

2. 点击浏览器右上角扩展图标，扩展会自动扫描页面里的 byteimg.com 无水印原图链接，并默认选中推荐项。

3. 在「保存文件名」里填提示词 ID（会自动递增），点「下载到 pm-images」。

4. 回到 Claude / Agent 说一声，或自己运行：node scripts/import-generated-images.mjs --dir ~/pm-images --apply。

常见问题

没检测到图片？先刷新即梦页面，再点扩展里的「刷新检测」；仍不行就把审查元素里 p*-dreamina-sign.byteimg.com 的 URL 粘贴到弹窗的「图片 URL」里。

没有「选择文件夹」选项或报错？这是 Chrome 的文件系统访问权限；更新 Chrome 到最新版。若仍不可用，扩展会回退到浏览器下载：弹保存对话框时选一次 ~/pm-images，Chrome 会记住。

下载的是水印图？请选列表里的 dreamina-sign / aigc_resize 链接（通常默认选中的就是无水印原图）。
