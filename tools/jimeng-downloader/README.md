# 即梦无水印下载器（Chrome 扩展）

从即梦（Dreamina）页面提取**无水印原图** URL，一键保存到本机 `~/pm-images/`，文件名使用 PentaPrompt 的提示词 ID（如 `16.webp`），方便直接跑批量导入脚本。

> 即梦页面显示的图带水印，但页面里引用的签名直链（`p*-dreamina-sign.byteimg.com/...aigc_resize...webp`）返回的是无水印原图——扩展就是把这些 URL 找出来并下载。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本文件夹：`tools/jimeng-downloader`
4. 固定到工具栏（可选）

## 首次设置

1. 点扩展图标 → **选择文件夹**（会打开展示设置页）
2. 选择本机的 `~/pm-images` 文件夹（就是存放补图的目录）
3. 允许 Chrome 的权限提示

> 浏览器不会显示完整路径，只显示文件夹名；请自己确认选的是 `pm-images`。
> 第一次选择后扩展会记住这个文件夹；如果重装扩展/清除浏览器数据，需要重新选一次。

## 使用

1. 在即梦打开生成结果页面
2. 点扩展图标，扩展会自动扫描页面（优先选 `dreamina-sign` / `aigc_resize` 的链接，默认选推荐项）
3. 在「保存文件名」里填提示词 ID（默认自动 = 上次 +1）
4. 点 **下载到 pm-images**

下载完成后回到 Agent 说一声，或自己运行：

```bash
node scripts/import-generated-images.mjs --dir ~/pm-images --apply
```

（脚本会转 WebP、上传 R2、更新数据库、备份旧 URL；之后重新部署即可。）

## 兜底方案

- **扫描不到**：刷新即梦页面 → 点「刷新检测」；仍不行，用开发者工具找到 `p*-dreamina-sign.byteimg.com/...` 的 URL，粘贴到弹窗的「图片 URL」输入框。
- **选不了文件夹**（老版 Chrome）：扩展会回退到浏览器下载对话框，打开时选一次 `~/pm-images`，Chrome 会记住上次文件夹；文件名确认后保存即可。
- **批量**：一张一张点比较适合边生成边补；如果想一次性下载多张，可以让 Agent 用脚本/命令行处理。

## 隐私

扩展只在即梦/剪映域名上读取页面里已加载的图片 URL，并把图片下载到你选择的本地文件夹；不上传任何页面内容、不收集数据。
